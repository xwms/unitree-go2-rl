# Go2 多任务系统设计

目标：在 Go2（四足 + 机械臂）上实现一组任务——走楼梯、迷宫避障、跟黑线、跳过障碍、机械臂抓取——并统一调度执行。

核心思路是**分层混合**：RL 只解决接触丰富的运动技能（楼梯/跳跃/速度跟踪），导航用成熟经典栈（Nav2），跟线用经典 CV+控制，抓取用模仿学习；各技能通过行为树编排，导航类技能统一输出 `cmd_vel`。

## 1. 总体架构

```
┌────────────────────────────────────────────────────┐
│ 任务编排层：行为树（py_trees / BehaviorTree.CPP）   │
│   技能序列、切换条件、失败恢复                      │
├────────────────────────────────────────────────────┤
│ 技能层（各用最优技术）                               │
│   迷宫避障 → Nav2（LiDAR SLAM + costmap + 规划）    │
│   跟黑线   → 下视相机 CV + PID                      │
│   抓取     → 模仿学习策略（ACT / Diffusion Policy） │
│   楼梯/跳跃 → RL 策略（直控模式）                   │
├────────────────────────────────────────────────────┤
│ 运动层：RL locomotion 策略                          │
│   cmd_vel 或目标位姿 → 12 维关节目标（50Hz）        │
├────────────────────────────────────────────────────┤
│ 硬件层：Go2 板载 PD + 机械臂 + DDS 通信             │
└────────────────────────────────────────────────────┘
```

## 2. 各任务方案

| 任务 | 方案 | 输入 → 输出 | 训练/实现方式 |
|---|---|---|---|
| **楼梯** | RL（现有 go2_stair 管线，两阶段） | 522 维观测（本体 81 + 高度图 441）→ 12 维关节 | Isaac Lab + PPO；Stage1 金字塔导航 → Stage2 直梯/L 形/螺旋 |
| **跳过障碍** | RL 专用技能 | 高度图 + 本体 → 12 维关节 | 新任务：障碍高度课程（5cm 起递增）、高动态奖励（速度追踪 + 腾空 + 落地稳定） |
| **迷宫避障** | Nav2 | LiDAR/里程计 → `/cmd_vel` | SLAM（建图/定位）+ costmap + 全局规划 + DWB/MPPI 局部控制 |
| **跟黑线** | 下视相机 CV + PID | 相机图像 → `/cmd_vel` | HSV 颜色分割 / RANSAC 直线拟合 → 横向偏移 + 朝向 → PID |
| **机械臂抓取** | 模仿学习（ACT / Diffusion Policy） | 视觉 + 臂关节 → 臂动作 | 遥操作采集演示 → 训练 IL 策略；腿部保持支撑或做平衡补偿 |

为什么这样分工：

- 楼梯/跳跃是接触丰富的高动态运动，经典控制不可靠，sim-to-real RL 是成熟方案；
- 迷宫是结构化导航，Nav2 这套经典栈成熟、可解释、安全，优于端到端 RL；
- 跟线不需要学习，经典 CV + PID 更快更稳；
- 真实世界 RL 抓取样本效率太低，固定场景抓取当前 SOTA 是模仿学习。

不采用的方案：端到端多任务大模型（VLA 类）需要海量数据与算力，当前单卡 6000 与四个任务规模不匹配，且失去分层可调试性。

## 3. 统一接口

- **导航接口**：所有导航类技能（Nav2、跟线）输出 `geometry_msgs/Twist`（vx, vy, wz），由 RL 运动层订阅执行；输出需限幅与插值（Nav2 控制频率 ~10-20Hz，策略 50Hz）。
- **直控模式**：楼梯/跳跃技能绕过 `cmd_vel`，接收目标位姿或触发信号，直接接管运动层。
- **模式切换**：编排层通过 `/task_mode`（walk / stairs / jump / grasp / idle）选择策略；切换时先归零速度、站定过渡，避免动作跳变。
- **RL 观测约定**：本体 81 维 + 高度图 441 维固定；任务特定观测统一 padding 到固定长度，保证各运动策略可互相 resume/混合训练。
- **动作约定**：运动策略统一 12 维腿关节目标；机械臂任务单独 18 维（腿 12 + 臂 6），接口带维度标记。

## 4. 实施阶段

| 阶段 | 内容 | 依赖 |
|---|---|---|
| M1 楼梯（进行中） | Stage1 续训至收敛 → Stage2 训练 → eval 验收 | 现有 go2_stair 管线 |
| M2 velocity 底盘 | 速度跟踪策略（平/不平地形），从楼梯 checkpoint 微调或新训 | M1 的步态基础 |
| M3 仿真集成 | ROS2 骨架：Nav2 迷宫 + 跟线节点共用 `/cmd_vel`，接底盘策略 | M2 |
| M4 跳跃技能 | RL 任务：障碍高度课程 + 高动态奖励 | M2 的网络与管线 |
| M5 机械臂抓取 | 遥操作采集 → IL 训练 → 部署 | 硬件（Go2 + 臂）、仿真资产 |
| M6 串联 | 行为树编排 + 真机验证（小场景到全任务） | M3-M5 |

## 5. 风险与待定

- **定位**：Nav2 依赖 SLAM/定位；楼梯段 LiDAR 易漂移，梯段切换建议用腿部里程计或时序判断；
- **切换安全**：策略切换的动作跳变需要过渡状态 + 失败回退（摔倒/卡住/超时）；
- **硬件清单**：LiDAR（Go2 自带 L1）、下视相机、臂上相机需确认；
- **仿真资产**：机械臂 USD 模型与 Go2 装配需准备（可参考 unitree_rl_lab 的 G1 mimic 管线）；
- **sim2real**：运动策略需域随机化 + 真机限幅安全测试。
